# Agent-Skills

Skills für Claude Code aus [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
(MIT-Lizenz, Stand: Commit `063bee9`, 28.08.2026). Claude lädt sie automatisch, wenn eine Aufgabe passt.

| Ordner | Skill | Wofür |
|---|---|---|
| `react-native-skills` | `vercel-react-native-skills` | React Native und Expo: Listen, Animationen, Navigation, native Module |
| `react-best-practices` | `vercel-react-best-practices` | React-Performance: Re-Renders, Datenladen, Bundle-Größe |
| `composition-patterns` | `vercel-composition-patterns` | Komponenten-Aufbau, Compound Components, React-19-APIs |
| `web-design-guidelines` | `web-design-guidelines` | UI-Prüfung (Barrierefreiheit, UX) – vor allem für die Web-Version |

Nicht übernommen: die Vercel-Deployment-Skills (`deploy-to-vercel`, `vercel-cli-with-tokens`, `vercel-optimize`),
weil die App über Expo/EAS veröffentlicht wird, sowie `react-view-transitions` und `writing-guidelines`.

Aktualisieren: Ordner durch die neue Version aus dem Repository ersetzen.
